# comandos

Español | [English](README.en.md)

Bloc de notas de comandos por proyecto: un título, el comando debajo y un botón
para copiarlo.

## Uso

`/comandos` abre o cierra el panel con las notas del proyecto actual.

Para añadir una, escribe el título en «Para qué sirve», pulsa Enter, escribe el
comando y pulsa Enter otra vez. Si dejas el título vacío se usa el principio del
comando.

Cada nota tiene dos botones: **Copiar**, que deja el comando en el portapapeles,
y **Borrar**.

## Datos

Cada proyecto tiene sus propias notas, según la carpeta de la sesión, hasta 100.
Se guardan en local. No guardes secretos en los comandos: quedan en claro en ese
archivo.

No llama a ningún modelo ni hace peticiones.
