# comandos

[Español](README.md) | English

A per-project command notebook: a title, the command below it and a button to copy
it.

## Usage

`/comandos` opens or closes the panel with the current project's notes.

To add one, type the title in "Para qué sirve" (what it is for), press Enter, type
the command and press Enter again. If you leave the title empty, the start of the
command is used.

Each note has two buttons: **Copiar** (copy), which puts the command on the
clipboard, and **Borrar** (delete).

## Data

Each project has its own notes, based on the session's folder, up to 100. They are
saved locally. Do not store secrets in the commands: they stay in plain text in
that file.

It calls no model and makes no requests.
